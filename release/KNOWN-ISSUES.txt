FF4 JOBS+ 0.3.0 playtest — known limits

A complete campaign and native Windows/clean-prefix installation have not
been certified. Keep backup saves and use a separate test slot.

Ranger Rapid Fire, Red Mage Dualcast, Ninja Dual Wield, Monk Barehand and
personal mastery are implemented. They need live combat/controller acceptance
and full-campaign balancing; build/core checks are not a campaign playthrough.
This is an FF4/FF5 hybrid, not an exact recreation of every FF5 mechanic.
Native elemental effects, defenses, status rules and counters remain relevant.

Native character identity, slot restrictions and FF4 combat calculations
remain. Equipment eligibility is changed by the main job; uncommon story,
Optimize, full-inventory and magnetic-cave interactions need campaign QA.

The English Jobs UI is not localized. Other gameplay/UI/save mods are
unverified. The plugin only enables on the recorded GameAssembly hash.

The isometric experiment, VSync changes and keyboard remaps are separate
and are not included. Development diagnostics require the explicit
FF4JOBS_TEST_MODE=1 environment variable; normal launches do not run them.

Native command scrolling/triangles and Cecil HP casting were approved in the
previous live playtest. The new advanced-job changes need their own live pass.
